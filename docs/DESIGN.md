# DESIGN

> 工具是新的，工作台不稀奇。我们要做的是**你自己的那片夜空**。

## 1. 美学方向

**古典星图册**（Classical Star Atlas） + 现代排版 + 中世纪航海图遗韵。

具体来说：
- 17-18 世纪欧洲星图册（Hevelius《Uranographia》、Bayer《Uranometria》、Cellarius《Harmonia Macrocosmica》那一脉）
- 18-19 世纪博物学家田野笔记的手绘笔触
- 旧航海图：罗盘玫瑰、经纬线、海怪、藏宝图边角

**为什么这套语汇契合 Radar Quest：**
- Radar（雷达）= 在天际搜寻信号，星图天然契合
- Quest（任务）= 探险旅程，藏宝图、远洋船、罗盘、六分仪都是现成的视觉符号
- "浪漫" = 故事书 + 夜空 + 暖调墨水 + 笔触手绘，避开"赛博""匠人""极简"那种冷感

**绝对不做：**
- 匠人工作台、暗色 Linear 复制品
- 纯白 productivity app
- 霓虹赛博、玻璃拟态、渐变紫
- 卡通 RPG、表情包、像素风

## 3. 字体

- **Display / 标题**：`Fraunces`（人文衬线，带 optical sizing，浪漫但不甜，是星图册标题的现代对应物）
- **正文**：`Inter`
- **数据 / 数字**：`JetBrains Mono`
- **大数字（XP、Level、计数）**：`Fraunces` 大字号 + optical sizing + tabular nums

字体加载：next/font（self-host，subset 中文常用字）

## 4. 手绘资产

### 风格指南
统一提示词方向：
```
钢笔线稿 + 极淡水彩晕染，18 世纪博物学手绘 / 古星图册风格，
背景留白，线条有粗细变化，inspiration from Hevelius Uranographia,
Ehret botanical plates, Audubon bird illustrations
```

### 资产清单（v1）

**Logo / Wordmark**
- 1 张：「Radar Quest」手写体 wordmark，可带六分仪或罗盘玫瑰

**空状态（3 张）**
- 夜色帆船：用于"还没有任何 items"的 dashboard
- 空卷轴：用于"还没有任何笔记"的状态
- 未完成的星座：用于"还没有任何 Publish"的状态

**成就徽章（12 个）**
- 古星图符号风格，每个对应一个成就：
  1. 初见（First Watch）
  2. 收藏家（10 Saves）
  3. 笔记家（10 Notes）
  4. 匠人（10 Builds）
  5. 首发（First Publish）
  6. 三连击（Save→Note→Build 同一 item）
  7. 告别吃灰（10 Saves 中至少 1 条 30 天内变 Publish）
  8. 百日行动（100 天行动 streak）
  9. 月度输出（4 周连续输出 streak）
  10. 主题均衡（三技能树差距 ≤10%）
  11. 远征者（完成 1 个 Boss）
  12. 群星（点亮 50 颗 Publish 之星）

**Boss 形象（3 个）**
- 神话海怪（海蛇 / 克拉肯）
- 古天文图怪兽（天龙 / 凤凰）
- 神秘天象（日食 / 流星雨）
- 配色与手绘笔触保持一致

**装饰分割线（5 段）**
- 卷草
- 星座连线
- 罗盘玫瑰
- 经纬线
- 浪花

**装饰元素**
- 罗盘玫瑰
- 六分仪
- 望远镜
- 藏宝图边角（4 角）
- 星座连线模板

**背景纹理**
- 极淡星点（5% 透明度），用于主页夜空
- 羊皮纸噪点（2% 透明度），用于卡片底

## 5. 动效

### 调性
- **不**做：弹性反弹过猛、卡通 bounce、玻璃弹跳
- **要**做：缓入缓出、轻微光圈、月升月落、星座连线绘制、墨水笔触

### 关键动效

| 动作 | 动效 | 时长 |
|---|---|---|
| XP 上涨 | 数字滚动 + 顶部金色光圈扩散 | 400ms |
| 任务打勾 | 墨水笔触划线 | 300ms |
| 升级 | 星座背景渐亮 + Fraunces 标题大字淡入 | 1500ms |
| Boss 击破 | HP 槽削减 + 数字敲击 + 短促金色粒子 | 800ms |
| Tab 切换 | 星图"翻页"感（轻微旋转 + 淡入） | 350ms |
| 成就解锁 | 右上角滑入通知卡 + 短暂高亮 | 进 300ms / 停 2.5s / 出 500ms |
| 技能树填充 | 弹性 spring | 600ms |
| 卡片 hover | 上升 2px + 暖光描边 | 200ms |
| 背景氛围（Full+ 档）| 星座连线极慢绘制 | 持续 |

所有动效用 `motion`（原 framer-motion）实现，遵守 `prefers-reduced-motion`。

## 6. 音效

### 调性
- **不**做：8-bit、叮咚、电子音效
- **要**做：音乐盒、风铃、远洋钟声、纸页翻动、羽毛笔划写、海浪

### 音效清单

| 触发 | 声音 | 时长 |
|---|---|---|
| Watch | 极轻风铃 | 0.2s |
| Save | 书页翻动 | 0.3s |
| Note | 羽毛笔划写 | 0.4s |
| Build | 木材 / 金属轻击 | 0.3s |
| **Publish** | **远洋钟声 + 弦乐上扬** | 0.8s |
| 升级 | 上行音乐盒 3 音 | 0.6s |
| Boss 击破 | 低频海浪 + 短促凯旋 | 1.0s |
| 断 streak | 单音下行 | 0.4s |

每个文件 <10KB。封装 `useSound` hook，统一管理。

## 7. UI 组件

### 全局元素
- 顶部细条：Level · 今日 XP · Streak · 活跃 Boss 数
- 侧栏：今日任务卡 · 三技能树 · 活跃 Boss
- 主页：你的夜空（过去 30 天星图）+ 5 Tab 入口
- 设置入口：右上角齿轮

### 卡片（item-card）
- 来源平台 logo（小、灰阶）
- 标题（Fraunces 衬线，hover 时暖光描边）
- 一句摘要（Inter，2 行截断）
- 主题标签（3 主题，色点表示）
- 5 动作按钮：👀 🔖 📝 🛠 📢（小图标 + 简短文字 tooltip）
- 已记录笔记预览（如有）

### 主页星图视图
- 全屏深色画布
- 30 天的所有 action 散落为星点
- Watch = 暗白小点
- Save = 稍亮
- Note = 淡黄
- Build = 暖橙
- Publish = 蓝白光星 + 光晕
- 鼠标悬停显示该点的 item 标题
- 点击跳转到该 item 的卡片视图

## 8. 移动端

- v1 桌面优先
- 移动端**能读 + 关键操作能用**
- 关键操作：浏览 5 Tab、记录 Watch/Save/Note、查看今日任务
- 次要操作（创建 Boss、改设置）在移动端可读但建议回桌面

## 9. 国际化

- `next-intl` 框架
- `zh-CN` 为主，`en` fallback
- 关键文案两套：UI 文案（菜单、按钮）+ 教程 / 空状态（"你的星图在等你点亮第一颗星"）

## 10. 可访问性

- 键盘导航全支持
- ARIA 标签完整
- 色彩对比度 ≥ WCAG AA
- `prefers-reduced-motion` 时关闭动效
- 音效默认关，用户主动开
