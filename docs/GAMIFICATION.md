# GAMIFICATION

> 行动即奖励。XP 是影子，不是目标。**真正的"升级"是你产出了一个作品。**

## 1. 设计哲学

StarCatcher 的游戏化不是"为了让你打开更多次"。
它的存在只有一个目的：**把"看到热点"这件松散的事，绑到一个明确的、有节奏的"做出作品"的回路上。**

所以这套机制：
- **强的是 Publish**。所有 XP 计算、所有徽章、所有 Boss 进度，都把 Publish 当成最有重量的节点
- **轻的是 Watch**。看一眼几乎不计分，但它**确实会被记录**（淡白小点）
- **克制的反馈**。动效有，但不喧哗。音效有，但默认关

## 2. 5 个动作层级

每条 item 都可以被赋予 5 个动作（递增承诺）：

| 动作 | 含义 | XP | 视觉 |
|---|---|---|---|
| 👀 Watch | 扫了一眼，知道这事 | 5 | 暗白小点 |
| 🔖 Save | 收藏了，打算回来看 | 10 | 稍亮白点 |
| 📝 Note | 写了一句话"对我有什么用" | 20 | 淡黄星 |
| 🛠 Build | 动手做点什么（跑通 / 试一下 / fork）| 50 | 暖橙星 |
| 📢 Publish | 产出了作品（公众号 / 开源 / 发推）| 100 | **蓝白光星 + 光晕** |

**对同一 item，状态是累加的**：Watch 后再 Save，item 状态是 Saved；再 Note，是 Noted。Publish 时自动连带触发前面所有节点的视觉回放（"三连击"成就）。

## 3. 等级

- 起始 Level 1
- 每 100 XP 升一级
- Level 公式：`level = floor(xp_total / 100) + 1`
- 没有等级上限。慢慢升

## 4. 技能树（3 条）

每条技能树对应一个主题。**不是手动选**，是按你 Note / Save / Build / Publish 时的 item `topics` 自动累加。

| 主题 | 颜色 | 里程碑 |
|---|---|---|
| AI 应用 | `#5FE0C7` 星辉青 | 10 / 25 / 50 / 100 / 250 |
| 一人公司 | `#E8B86F` 琥珀金 | 同上 |
| 自我管理 | `#B8A4D4` 雾紫 | 同上 |

**冷启动补偿**：如果某条技能树被冷落 7 天以上，下次相关动作 XP +50%（一次性的，再冷落再触发）。**这是为了防止"我只刷一个主题"。**

## 5. Boss 关卡

Boss 是你自己定义的长期战役。

**形态**：
- 名字（如"100 个 AI 作品"）
- 目标数（100）
- 截止日期（可空）
- 主题（AI / 一人公司 / 自我管理）
- 当前进度（自动从 Publish 动作累加）

**预置 Boss（v1 默认）**：
1. **公众号首发**：写完第一篇公众号文章。1/1，截止 2026-12-31

**完成奖励**：
- HP 槽归零时屏幕短暂金色粒子 + 远洋钟声
- 该 Boss 标记为 completed，移入"Boss 档案"页
- 解锁"远征者"成就
- 自动建议建下一个 Boss

**用户可手动添加**：设置 → Boss 管理。

## 6. 双 Streak

| Streak 类型 | 判定 | 默认宽限 | 断的影响 |
|---|---|---|---|
| 行动 streak | 每天至少 1 个动作（任一类型）| 1 天 | 计数归零，不告警 |
| 输出 streak | 每周至少 1 个 Publish | 0 周（按周计）| 计数归零 |

**Streak 显示位置**：顶部统计条、主页星图角标。

## 7. 每日任务

每天自动从当日热点里抽 N 个（默认 3，可调 0-5）作为今日任务卡。

**抽法**：
- 跨主题混合（不能 3 个都 AI）
- 跨来源混合（不能 3 个都 GitHub）
- 难度混合：1 个 Watch、1 个 Save、1 个 Build
- 重复出现过的 item 优先级降权

**完成奖励**：全做完 = 额外 30 XP。

**设置项**：
- daily_quest_count: 0 / 3 / 5
- 关闭：daily_quest_count = 0

## 8. 成就（12 个预置）

| ID | 名称 | 条件 |
|---|---|---|
| first_watch | 初见 | 完成 1 次 Watch |
| first_save | 收藏家 | 完成 1 次 Save |
| first_note | 笔记家 | 完成 1 次 Note |
| first_build | 匠人 | 完成 1 次 Build |
| first_publish | 首发 | 完成 1 次 Publish |
| triple_strike | 三连击 | 同一 item 完成 Save→Note→Build |
| no_dust | 告别吃灰 | 10 个 Saves 中至少 1 条 30 天内变 Publish |
| hundred_days | 百日行动 | 100 天行动 streak |
| weekly_output | 月度输出 | 4 周连续输出 streak |
| balanced | 主题均衡 | 三技能树差距 ≤10% |
| voyager | 远征者 | 完成 1 个 Boss |
| constellation | 群星 | 点亮 50 颗 Publish 之星 |

## 9. 灵感卡组

"过去 30 天 Save 但还没 Note / Build 的 item"+ "关键词聚类" → 每天推 1-3 张"关联卡片"。

**形态**：
- 卡背：手绘星座连线
- 翻开：3-5 条相关 item 列表 + 主题色边框

**意义**：这就是"聚类"功能，只是披上了卡牌外衣。

## 10. 强度分级（4 档预设 + 独立开关）

### Level 0 · Pure Data（关掉游戏化）
- 所有游戏化元素隐藏
- 5 Tab、RSS、设置照常工作
- 视觉：纯数据型 dashboard

### Level 1 · Stealth（低强度 ~30%）
- XP / 技能树**后台算**但**不显示**
- 无每日任务、无音效
- Boss 进度低调显示
- 动效：仅 hover / click 基础

### Level 2 · Standard（中强度 ~60%，默认）
- 顶部统计条（Level/XP/Streak/Boss）
- 侧栏今日任务卡（3 个）+ 技能树 + 活跃 Boss
- 动效：XP 滚动 / 等级提升 / 技能树填充
- 成就：弹层通知

### Level 3 · Full（高强度 ~90%）
- Standard + 任务 5 个 / 动作反馈更厚 / 背景氛围 / 音效默认开
- 定时推送（按提醒时间）
- 自动建议 Publish 候选（14 天以上未 Publish 的 Note）

### Level 4 · Hardcore（极强度 ~100%）
- Full + 任务反馈更强烈 / 无宽限期 / 周复盘视图更突出
- 适合冲刺

### 独立开关（任何档位之上）

| 开关 | 范围 | 默认 |
|---|---|---|
| 音效 | off / action / publish / all | publish |
| 动效 | off / subtle / standard / rich | standard |
| 每日任务数量 | 0 / 3 / 5 | 3 |
| Streak 宽限 | 0 / 1 / 2 / 3 天 | 1 |
| 提醒时间 | off / 早 / 晚 / 自定义 | off |
| 背景氛围 | off / subtle / 明显 | subtle |
| Publish 提醒 | off / 7 / 14 / 30 天 | 14 |

**"开 70%"含义**：Level 3 + 动效 rich + 音效 publish。

## 11. 反向校验（要避免的）

- **不要变打卡工具**。积分高 ≠ 你真的输出了。设计里靠 Publish 高分 + 输出 streak 校准
- **不要喧宾夺主**。默认半透明，可一键关。**真正的"游戏"是你在现实里做出了作品**
- **不要在动作面板上花太多设计时间**。1 键完成，不要 5 步弹窗
- **数据可导出**。所有动作 / 笔记 / 输出关联可导出 JSON / Markdown
