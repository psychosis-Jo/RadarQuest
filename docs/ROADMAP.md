# ROADMAP

## v1（这次做完）— 核心闭环

- 6 个数据源（GitHub / PH / HN / Reddit / Newsletter / 公众号）
- 5 个 Tab 榜（Trending / 短时间爆发 / 持续上升 / 讨论密度 / 跨平台提及）
- 5 个动作（Watch / Save / Note / Build / Publish）
- 3 主题技能树 + XP / Level / 双 streak / 12 成就
- 自定义 Boss
- 4 档游戏化强度 + 7 个独立开关
- RSS 订阅
- 桌面 + 移动
- 中英双语
- 单用户、单设备、单实例

**v1 完成的硬标准**：见 BUILD_PLAN.md

## v2（个人使用 1-2 个月后）— 深度

- **历史曲线**：单条 item 的 metrics 随时间变化
- **跨时对比**：类似项目对比表（"LangChain vs LlamaIndex"）
- **AI 摘要**：每条 item 自动生成中文摘要
- **AI 聚类**：从全部 Note 里抽"主题"自动归类
- **更多信源**：X（即时通讯或第三方付费）、即刻、豆瓣、小红书
- **浏览器扩展**：Chrome 扩展，正式做"新标签页"
- **桌面通知**：定时推送今日任务

## v3（社区化）— 协作

- **多人**：加 Auth，每个用户独立
- **灵感卡组分享**：你可以公开某个聚类视图
- **Boss 进度广场**：看别人在打的 Boss
- **公开个人星图**：你的 30 天星图作为可分享的页面
- **订阅其他人的星图**

## 不做（明确）

- **AI 自动 Publish**。这条由你决定。StarCatcher 只做工具
- **评论 / 关注 / 点赞**等社交动作。这不是社区
- **替代 GitHub / PH / HN**。我们只聚合它们
- **移动 App 原生**。v1-v3 全部 Web
